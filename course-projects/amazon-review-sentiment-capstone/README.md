# Amazon Review Sentiment Capstone

This course capstone was completed in two structured phases. Both phases are retained to preserve the progression of the coursework and its original project documentation.

- [Phase 1: Logistic Regression](phase-1-logistic-regression/) establishes the preprocessing pipeline and evaluates logistic-regression models with Bag of Words, TF-IDF, and Word2Vec features.
- [Phase 2: Random Forest and VADER](phase-2-random-forest-vader/) extends the analysis with Random Forest comparisons and VADER sentiment analysis.
