# Course Projects

These projects are listed in course order so the progression from exploratory analysis through the final capstone remains visible.

1. [Customer Coupon Acceptance](customer-coupon-acceptance/) — exploratory analysis of factors associated with coupon acceptance.
2. [Used Vehicle Recommendation](used-vehicle-recommendation/) — regression analysis of the drivers of used-car prices.
3. [Classifier Comparison](compare-classifiers/) — comparison of classifiers for bank-marketing campaign outcomes.
4. [Amazon Review Sentiment Capstone](amazon-review-sentiment-capstone/) — a two-phase sentiment-analysis capstone covering logistic regression, Random Forest, and VADER.
